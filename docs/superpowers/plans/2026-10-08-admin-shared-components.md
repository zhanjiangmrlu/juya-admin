# 后台公共组件与配置抽离

目标：把已还原页面的重复展示结构集中管理，保持 Figma 外观与现有业务交互。

采用已有 `src/components` 和 CSS tokens，不增加依赖。配置位于 `src/app/admin-ui.config.ts`；通过 TypeScript 类型校验。此次配置由开发者维护代码，不新增服务器配置接口或管理表单。

组件边界：

- `AdminPanel`：统一卡片容器、标题级别、描述、表面与内容间距，保留 header/default/footer 插槽和原 ElCard 属性。
- `DataTable`：扩展已有表格，支持配置列名、字段、宽度、固定列、提示与隐藏，命名插槽保留业务单元格和按钮；原列插槽仍可用。表格事件转发给页面。
- `AppPagination`：页容量选项集中配置，也允许页面覆盖；未知总数和请求事件保持原行为。
- 公共标题、所有重复表格列与默认展示值集中管理。页面继续拥有筛选、权限、确认、API 和业务状态。

执行：当前对话直接 main 完成，不创建额外对话，不改接口和业务 composable。
