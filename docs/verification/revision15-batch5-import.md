- 恢复步骤采用服务端 `stage`。上传／处理中恢复时说明此前未完成上传的本地文件须重新选择。指定当前批次结果的 URL 和轮询使用普通 GET，因此全部完成结果仍可查看。

- 无效ZIP、音频格式不符等原文件错误需要修正重传，已接收本地队列、恢复文件列表、包内素材和实际重试函数统一过滤；处理中断和音频转换服务暂不可用等适用失败仍可重试。
