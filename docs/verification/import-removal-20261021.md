## 行为

- 已删除卡片不再参与普通或历史兼容导入判重；旧批次恢复及重新上传可以创建新草稿，旧卡片和历史关系保留

- 上传列表支持单个、全选及批量移除已接收ZIP；核对列表支持单卡及批量移除，重复项可选择，保存勾选保持独立
- 移除确认显示所选名称、数量及影响。已提交草稿保存的资料受到保护，其他文件继续上传、解析和保存

- 所选资料的待放弃修改不必先保存；已经发送但结果未知的写入须先确认，再以最新服务器修订生成移除范围
- ZIP移除数量不套用卡片数量上限，51个失败ZIP可以一次移除
