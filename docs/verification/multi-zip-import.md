# 多ZIP统一核对与批量保存草稿

2026-10-17，基于已批准的多ZIP方案实施；测试环境发布结果见文末。

## 行为与改动

- `import-upload-panel.vue` 与 `use-import-uploads.ts`：多选ZIP先进入清单，展示大小，可移除、开始上传和继续追加；单次传输并发为1，失败不打断后续文件。未知响应查询原凭证，确认已接收后不重传。
- `import-workflow-page.vue`：同批汇总ZIP数、可读卡片数、完整／待补充数量及分别统计的ZIP／卡片失败数；资料变化会撤销旧保存确认。
- 核对、素材选择和结果组件显示来源ZIP及完整文件夹路径；ZIP素材只允许在同一卡片文件夹选择，后端同时校验。
- 保存失败重试冻结失败卡片ID，确认列表和提交范围一致，新增／成功项目不随重试写入。
- 后端沿用逐文件上传、持久导入批次、逐卡草稿任务；补充实际解析进度、完整及不完整对象去重和历史记录兼容。

## 启用与边界

- 先执行后端新增Alembic迁移0011，再更新管理API、管理Worker和管理前端；小程序角色仍兼容0010，不需要为本功能更新。
- 保留当前配置上限：默认单ZIP100MB、展开500MB、每批50张卡片；没有扩大容量或并发。
- 浏览器待上传文件只保留在当前页面，刷新前会提示；刷新后需重新选择未上传文件。服务器已接收文件、核对暂存和保存结果可恢复。
- ZIP仍为一文件夹一卡片，文件夹内多卡DOCX提示拆分；原独立DOCX入口保留多卡文档支持。
- 导入仅保存草稿，缺资料不能发布；没有新增音频生成或单词音频上传。
