# 修订15 · 第三批后台反馈验证

日期：2026-10-22。范围为已批准方案3.3、基线33及T169—T178的管理员侧A08/A09；未扩展数据统计指标或只读场景预览的用户业务。

## 实现

- A08使用真实反馈API完成搜索、四态筛选、每页10条、用户内部编号、安全来源双标题及未读补充标识；列表GET不清未读。返回保留查询条件、页码及滚动位置，刷新失败保留最后可信记录
- A09展示完整有序时间线、安全来源摘要及会话绑定截图。截图直接使用服务端grant，失败后续签同一附件，不上传或构造公开图片地址
- 普通回复保留状态，开始处理、要求补充和标记已处理为明确动作；后两项必须提供说明。状态动作带已显示事件水位，冲突或失败保留输入，刷新核对后由管理员重新确认
- 未知回复先查询原幂等键；仅查询确认尚未接受后允许明确原键重试。恢复成功后重读当前详情，避免历史回执覆盖后续补充；刷新失败保留确认快照并阻止基于旧水位继续操作
- 已读写仅在时间线实际渲染后提交最高已显示事件；未知回执先查原操作，再重查未读聚合。最小ack不直接清空新红点
- 会话失效停止提交；正文仅按管理员与反馈编号保存在当前进程内存。确认同一身份后恢复输入及本人待确认操作，不自动提交，不把正文写入sessionStorage/localStorage。成功响应晚于身份变化时保留原管理员的查询凭证

## 设计与契约

已获取Figma A08列表／失败、A09详情／来源失效节点的设计上下文及截图，沿用现有Vue、SCSS、全局颜色、字体与管理壳层。三个反馈SVG来自对应Figma资产，原始尺寸分别20×20、8×8、16×20。

API以`docs/implementation/feedback-api-contract.md`最终DTO为准。`openapi/admin.json`复制自API仓库导出并由`pnpm generate:api`生成声明，反馈页面使用生成类型别名。没有页面运行时fixture或合成安全服务。
