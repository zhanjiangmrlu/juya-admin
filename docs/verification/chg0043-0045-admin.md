# CHG0043—0045 管理后台本地交付

基于 `test` 的 `97bd6ea7b2fc34edcb6e516933e7eb1e5d86e3f5` 在隔离 worktree 实现。只修改后台仓库，未推送或部署；账号、原本地环境与生产数据保留。学习授权和内置查词继续暂停。

## 实现与口径

- 场景列表增加明确类型筛选、发布归属、草稿拟改类型和发布 PDF；单篇及 DOCX、ZIP 核对提供图解／精读选择、原始类型说明及 PDF 冲突提示。缺类型和冲突可以保存草稿，发布预览仍由服务端统一拒绝，前端不根据 PDF 推导类型。
- ZIP 批量类型先暂存现有编辑，再请求 preview；默认只补空值，覆盖须显式勾选。确认展示稳定候选 ID、原值、新值、实际数量和 PDF 冲突，apply 使用冻结版本及幂等键。重复项不进入类型范围，暂存入口也拒绝重新勾选的重复项。
- 旧卡核对读取当前发布的建议、附件依据和异常；管理员选中及确认后才提交版本快照。逐项回执保留成功或待重新核对原因。双分类启用是另一次明确确认，由服务端重验，未归类不会被前端默默启用。
- 场景和听读编辑／导入复用服务端 `vocabulary/sources/preview`。可靠词形显示“自动通过／无需手动确认”，支持仅异常核对、定位修正和移除；显示资料词、正文实际词形、原句及可读原因。人工修正场景来源时明确更新原句提示，保留 UTF-16 范围。听读直接展示服务端 Unicode 码点来源。过期预览不能覆盖新输入，不另写一套自动匹配规则。
- 两模块重复明细使用持久批次接口按 20 条分页，区分已有内容、同包、跨 ZIP；展示源 ZIP、内部路径、双语标题、目标种类及稳定 ID。不可用目标禁用；候选定位当前批次，正式内容带返回来源，恢复批次后仍可查询。
- 两列表四统计直接读取同一组合响应的 `statistics`、`all_statistics`、`snapshot_at`，不按搜索、状态或选择重算。失败显示不可用或保留旧快照未刷新，不转为 0。
- 每页 10 条，严格文本跳页，按钮／回车共用校验；前导零可规范化，非法值不请求、不清输入和选择。路由切页前读取目标组合响应，成功才提交页码与普通选择清理，失败保留原页及勾选。服务端有效页负责末页回退。免费模式跨页保留稳定 ID，类型条件参与原有丢弃确认，取消恢复控件和 URL。成功换页定位表格，编辑返回沿用来源与位置恢复。
