沿用当前 `feature/v1.5-20261011` 分支，修改 `juya-admin` 和 `juya-admin-api`，未向远端推送或向测试／生产服务器部署。实际内容、旧发布快照、收藏、数据库和本地服务配置保留。

## 删除与兼容

删除旧图片创建内容的上传队列、上传 Adapter、旧校验器、闲置进度组件及其过时测试；移除旧可点击词卡弹层、旧多入口工作流。图片保留为候选草稿的选填素材，统一内容 ZIP 为推荐导入。

OCR 已取消，不显示创建入口；历史 OCR 深链保留明确退役说明，浏览器不调用 OCR。历史音频版本、已发布快照与下线内容引用继续可追溯，未删除相关数据或后端兼容接口。

## 验证与实际边界

前端完整格式／ESLint／Stylelint／类型检查及生产构建通过；104 个单测文件、374 项测试通过。浏览器覆盖 92 项业务回归与 54 项视觉检查。最后全量业务回归 91 项通过，剩余一项是测试导航工具错误要求保留伪造的 `material_phase=result`；应用已正确恢复实际 `upload`。修正工具并等待真实路由完成后，材料与目录 5 项定向复验全部通过，同时加强迟到候选响应的实际网络完成断言。没有遗留产品功能失败。

浏览器命令通过本地独占 4179 端口的同配置执行，避免影响既有 5173 页面及其他任务。常规复验：`pnpm check`、`pnpm test --maxWorkers=2`、`pnpm build`、`pnpm test:e2e`。本地截图位于 `.impeccable/review/`，真实服务截图为 `.impeccable/review/v15-restoration/local-content-production.jpg`。

契约从真实挂载的 172 个操作重新导出并生成前端类型。本地四个管理 API／Worker／Beat 进程更新时保留原环境，健康检查确认 MySQL、schema、Redis、configuration 就绪；实际浏览器已读取新版内容目录。
