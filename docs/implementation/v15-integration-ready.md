## 请求层检查

- FormData 由浏览器生成 boundary；Cookie 使用 credentials=include。JSON 成功体无统一 data 包装，204 不解析 JSON
- 导入 / 素材 / 短文 / normal-bulk 使用 `Idempotency-Key`；传统权益 / 发布命令使用 `X-Idempotency-Key`，不全局替换
- 记录环境提交、method/path/status/request_id、当前 / 返回版本、服务结果与页面结果。失败以实际 code/message/details 分类，不写密码、Cookie、联系方式或签名 URL 到共享日志
- 401 清理登录；403 核对最新 CSRF；409 刷新后重新明确确认；413 调整包；SLICE_NOT_READY 仍处理中；收费结果 UNKNOWN 不重复计费调用
