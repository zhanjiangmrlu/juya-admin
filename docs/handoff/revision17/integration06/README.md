# 整合06／修订17后台接续

本轮仅修改隔离工作树 `codex/revision17-integration06`，配套同级 API 的整合06契约。未推送、部署或操作生产数据。需求真源与三端联调证据继续以同级 API 交接为准。

## 当前功能

- 听读管理仅文章／分类两个 Tab；旧主题和全局免费排序管理路由重定向。分类支持增改、完整版本排序、当前页选择及逐项删除引用反馈；文章只维护分类内篇序。
- 文章和场景列表逐条启用／关闭免费，使用独立 `free_revision`；每行独立 pending／失败／未知回执恢复。刷新真实状态与全量只读汇总时保留筛选、分页、勾选和位置，不重复提交其他选择。
- 编辑、导入和预览直接使用分类。发布版预览按发布分类解析名称，与草稿迁类独立。
- 可选重点词汇支持独立义项、稳定编号、增删排序、当前正文原句／实际词形选择和显式确认。使用 Unicode 码点范围及与 API 相同的原句、英文单词边界；正文变化会重新校验。无法确认的 DOCX 原句保留 `source_hint`。
- 词汇试听复用现有受控发音任务及音频焦点管理；仅使用已保存文章／批次的词条和版本引用。新修改先保存才能试听，不写学习成绩。预览中空词汇区整体隐藏。
- DOCX 帮助与新模板一致，兼容旧无词汇、含历史主题的模板。候选显示词汇数及来源问题；不可核对的词汇不计入可发布数。保留批次恢复、目标更新差异、fingerprint／revision、成功不重做及只选原失败项重试；候选暂存未知响应新增原回执恢复。

## 验证与接续

使用 Node 22.23.3、pnpm 11.25。完整验证：`pnpm check` 通过，`pnpm test` 56 文件／233 测试通过，`pnpm build` 通过；`git diff --check` 通过。单元测试仍可能输出既有 jsdom `HTMLMediaElement.pause()` 未实现提示；该提示不代表真实浏览器音频结论。

当前真实 HTTP 浏览器验收由 controller 使用隔离 SQLite、合成资料和私有会话运行。后台开发入口为 `http://127.0.0.1:5293`，代理独立 API `http://127.0.0.1:8291`。真实云词库／发音／ASR及微信设备待另验，不以合成媒体代替云服务结论。

新增 `tests/e2e/integration06-live.spec.ts`：通过 `JUYA_INTEGRATION06_STATE` 与 `JUYA_INTEGRATION06_FIXTURE` 显式提供本地会话及合成 fixture。fixture 包含 `category_id`、`article_id`，可选 `docx_path`／`zip_path`；只允许 localhost／127.0.0.1。四份依赖旧主题／M 数量契约的 live 测试明确标为历史停用。
